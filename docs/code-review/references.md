# References

External documentation consulted during the review, grouped by technology. Each entry notes which
finding(s) it supports and why.

Where a finding is based on observed behaviour in this repository rather than on documentation,
that is stated in [`findings.md`](./findings.md) itself and no reference is listed here.

> **Note on verification.** This review was carried out without live web access. The URLs below
> are canonical documentation pages for the technologies in use, cited so the implementing agent
> can confirm the reasoning against the current docs. **Where a recommendation depends on a
> fast-moving API — particularly TanStack Start's build/hosting setup, `@convex-dev/auth`'s
> pre-1.0 extension points, and Nitro's Vite plugin — the plan explicitly instructs the
> implementer to verify against the live documentation before writing code.** Treat those
> specific sketches as direction, not as API reference.
